# 01: 应用骨架与主题基座

**What to build:** 打开终端命令进入 TUI 后可以使用的最小骨架：事件循环、七个功能页（IP 查询、Claude 检测、GPT 检测、IP 评分、DNS 泄漏、WebRTC、网络连通）的导航空壳、卡片式主题组件层。这是全部后续票的地基（prefactor），本身已可演示：一个观感统一、可在页面间切换的应用壳。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 启动进入 TUI，可经键位在七个功能页间切换并可退出
- [ ] 卡片、徽章、key-value 行、渐变信任分条均经主题助手渲染；代码中不出现裸边框块与裸颜色常量
- [ ] 图标统一走 icon 表（Nerd Font 码位，品牌图标用 md-* 字形近似）；语义色走 THEME_* 常量（绿=结论/黄=警示·冷却·配额/红=错误·泄漏/青=强调/暗灰=次要）
- [ ] 终端窄于 90 列时三列卡片网格自动降级为单列，以布局组件单元测试验证
- [ ] 渲染组件与布局降级有单元测试，按红绿推进编写
